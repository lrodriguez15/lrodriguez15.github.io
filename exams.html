Quick exam 1 — Algorithms, operators and calculations

Tuesday 29 September 2026, 17:35–17:55 · 20 min · 100 points · Closed environment — Respondus LockDown Browser. Code section in the embedded Trinket editor. Thonny not permitted. No Macs.

Covers: 01-algorithms-and-programs, 02-program-components.

How it is graded

Part Points What earns them
A1–A5 3 each Correct choice. No partial credit.
B 5 Correct value with the intermediate step shown. Correct value alone: 3. Intermediate step correct but final arithmetic wrong: 2.
C1 algorithm 30 INPUT:/OUTPUT: lines present and correct (10). Numbered steps that compute s before A (10). Every step is a single, unambiguous action a hostile reader could execute (10).
C2 program 50 Runs without error on 3 4 5 (15). Prints 6.0 or 6 (15). Inputs converted with float() (10). Implements the algorithm written in C1, not a different one (10).
Technical requirements −2 each Name comment · algorithm in multi-line comment · meaningful names · input prompts · labelled output

A program with no algorithm above it scores at most 50 — C1 is zero, C2 is graded. An algorithm with no program scores at most 50 the other way. Both halves are the exam.

Quick exam 3 — The while loop

Tuesday 13 October 2026, 17:35–17:55 · 20 min · 100 points · Closed environment — Respondus LockDown Browser. Code section in the embedded Trinket editor. Thonny not permitted. No Macs (paper copy).

Covers: 05-while-loop, 06-while-practice.

How it is graded

Part Points What earns them
A1–A5 3 each Correct choice. No partial credit.
B 5 14. Nothing else.
C1 algorithm 30 INPUT:/OUTPUT: lines present and correct (6). A WHILE with the right test — balance below goal — and a step that adds the deposit and counts the month (12). The why it stops sentence names the quantity (balance grows by a positive deposit every turn) (6). The non-positive deposit check in main, before the function is called (6).
C2 program 50 months_to_goal returns the right value on the four checks (5 each → 20). The loop runs zero times when the balance already reaches the goal — (1000, 100, 1000) → 0 (5). No input()/print() inside the function (10). main() reads, refuses a non-positive deposit with the exact message, otherwise prints; file ends with main() (10). Implements the algorithm written in C1 (5).
Technical requirements −2 each Name comment · algorithm in multi-line comment · meaningful names · input prompts · labelled output

The 0 deposit is the whole point of the exam: a loop whose step does not move toward the exit never ends, and the only defence is to refuse the input before the loop. That check is worth 16 of the 80 points between C1 and C2.
