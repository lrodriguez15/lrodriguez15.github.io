Exams & rubrics

Respondus LockDown Browser Trinket for the code part no Thonny · no Macs

The shape never changes. 15 points of read and predict — five short programs, you say what they print or where they break. 5 points for one exact output. 80 points for one problem: the algorithm first (30), then the program that implements it (50). Every rubric is published here before the exam; nothing about how you are graded is a surprise.

Quick exams cover the previous week. The midterm (Fri 23 Oct) and the final (Tue 1 Dec) follow the academia's format and are described in Canvas.

Quick exam 1 — Algorithms, operators and calculations

Tuesday 29 September 2026, 17:35–17:55 · 20 min · 100 points · Closed environment — Respondus LockDown Browser. Code section in the embedded Trinket editor. Thonny not permitted. No Macs.

Covers: 01-algorithms-and-programs, 02-program-components.

How it is graded

Part Points What earns them
A1–A5 3 each Correct choice. No partial credit.
B 5 Correct value with the intermediate step shown. Correct value alone: 3. Intermediate step correct but final arithmetic wrong: 2.
C1 algorithm 30 INPUT:/OUTPUT: lines present and correct (10). Numbered steps that compute s before A (10). Every step is a single, unambiguous action a hostile reader could execute (10).
C2 program 50 Runs without error on 3 4 5 (15). Prints 6.0 or 6 (15). Inputs converted with float() (10). Implements the algorithm written in C1, not a different one (10).
Technical requirements −2 each Name comment · algorithm in multi-line comment · meaningful names · input prompts · labelled output

A program with no algorithm above it scores at most 50 — C1 is zero, C2 is graded. An algorithm with no program scores at most 50 the other way. Both halves are the exam.

Quick exam 2 — Conditionals and functions

Tuesday 6 October 2026, 17:35–17:55 · 20 min · 100 points · Closed environment — Respondus LockDown Browser. Code section in the embedded Trinket editor. Thonny not permitted. No Macs (paper copy).

Covers: 03-conditionals, 04-functions.

How it is graded

Part Points What earns them
A1–A5 3 each Correct choice. No partial credit.
B 5 23. Nothing else.
C1 algorithm 30 INPUT:/OUTPUT: lines present and correct (8). Three tiers as IF lines with the boundaries on the right side — 10 and 30 belong to the lower tier (12). The negative check in main, before the function is used (5). Function steps and main steps clearly separate (5).
C2 program 50 water_bill returns the right value on the four checks (5 each → 20). No input()/print() inside the function (10). main() reads, rejects negatives with the exact message, otherwise prints the bill; file ends with main() (10). Implements the algorithm written in C1, not a different one (10).
Technical requirements −2 each Name comment · algorithm in multi-line comment · meaningful names · input prompt · labelled output

A program that prints the right numbers from inside water_bill instead of returning them earns the 20 for values and loses the 10 for shape — that is the lesson of Friday’s session, and it is worth exactly what it says.
