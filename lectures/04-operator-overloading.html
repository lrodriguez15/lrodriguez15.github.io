Operator Overloading

operator+ operator== friend stream I/O

Overview

C++ allows you to redefine the behaviour of built-in operators (+, ==, <<, …) for user-defined types. This is called operator overloading. Used well, it makes user-defined types feel as natural as built-in ones; used poorly, it produces unreadable code.

Key topics:

  • Syntax and general rules
  • Member vs non-member (free / friend) implementation
  • Arithmetic and compound-assignment operators
  • Comparison operators
  • Stream insertion (<<) and extraction (>>)
  • Subscript and call operators

Notes

General Rules

  • You cannot change operator arity (a binary operator stays binary).
  • You cannot invent new operators or change precedence/associativity.
  • At least one operand must be a user-defined type — you cannot overload int + int.
  • Operators ::, ., .*, ?:, and sizeof cannot be overloaded.
  • Overloading && and || loses short-circuit evaluation — avoid it.

Member vs Non-Member

An operator overloaded as a member function receives the left-hand operand as the implicit this pointer. An operator overloaded as a non-member (free) function takes both operands explicitly.

  • Use a member for operators that modify the object: +=, -=, [], (), =, unary -.
  • Use a non-member for symmetric binary operators (+, ==, <) so that implicit conversions apply to both sides equally.
  • Declare the non-member as a friend if it needs access to private members.

Canonical Forms

Most operators follow a canonical pattern. Implementing += first and then defining + in terms of it avoids code duplication: 

T& operator+=(const T& rhs);            // member — modifies *this
T  operator+ (T lhs, const T& rhs) {    // free — lhs is a copy
    lhs += rhs;
    return lhs;
}

Comparison Operators

Define operator== and operator<; the rest can be written in terms of those two (or use the standard library utilities from <utility>).

Stream Operators

operator<< and operator>> must be non-member functions because the left operand is a stream (std::ostream / std::istream), not your type. They return a reference to the stream to allow chaining.

Code Examples

Arithmetic & Compound Assignment

#include <iostream>

class Vector2D {
public:
    double x, y;
    Vector2D(double x = 0, double y = 0) : x(x), y(y) {}

    // Compound assignment — member
    Vector2D& operator+=(const Vector2D& rhs) {
        x += rhs.x;
        y += rhs.y;
        return *this;
    }
    Vector2D& operator-=(const Vector2D& rhs) {
        x -= rhs.x;
        y -= rhs.y;
        return *this;
    }

    // Unary negation — member
    Vector2D operator-() const { return {-x, -y}; }
};

// Binary + built from += — free function (no private access needed)
Vector2D operator+(Vector2D lhs, const Vector2D& rhs) {
    lhs += rhs;
    return lhs;
}
Vector2D operator-(Vector2D lhs, const Vector2D& rhs) {
    lhs -= rhs;
    return lhs;
}

int main() {
    Vector2D a{1, 2}, b{3, 4};
    Vector2D c = a + b;       // (4, 6)
    Vector2D d = c - a;       // (3, 4)
    std::cout << c.x << " " << c.y << "\n";  // 4 6
    std::cout << d.x << " " << d.y << "\n";  // 3 4
}

Comparison Operators

#include <iostream>

class Fraction {
public:
    int num, den;
    Fraction(int n, int d) : num(n), den(d) {}

    // Equality — free friend
    friend bool operator==(const Fraction& a, const Fraction& b) {
        return a.num * b.den == b.num * a.den;
    }
    friend bool operator!=(const Fraction& a, const Fraction& b) {
        return !(a == b);
    }
    friend bool operator<(const Fraction& a, const Fraction& b) {
        return a.num * b.den < b.num * a.den;
    }
};

int main() {
    Fraction half{1, 2}, twoFourths{2, 4}, third{1, 3};
    std::cout << (half == twoFourths) << "\n";  // 1 (true)
    std::cout << (third < half)       << "\n";  // 1 (true)
}

Stream Insertion & Extraction

#include <iostream>
#include <string>

class Point {
public:
    double x, y;
    Point(double x = 0, double y = 0) : x(x), y(y) {}

    // Must be non-member: left operand is std::ostream, not Point
    friend std::ostream& operator<<(std::ostream& os, const Point& p) {
        return os << "(" << p.x << ", " << p.y << ")";
    }
    friend std::istream& operator>>(std::istream& is, Point& p) {
        return is >> p.x >> p.y;
    }
};

int main() {
    Point p{3, 4};
    std::cout << p << "\n";           // (3, 4)

    Point q;
    // std::cin >> q;                 // reads two doubles
    // std::cout << "Read: " << q;
}

Subscript Operator

#include <stdexcept>

class FixedArray {
    int data[10];
public:
    FixedArray() { for (auto& v : data) v = 0; }

    int& operator[](int i) {
        if (i < 0 || i >= 10) throw std::out_of_range("index out of range");
        return data[i];
    }
    const int& operator[](int i) const {   // const overload for read-only access
        if (i < 0 || i >= 10) throw std::out_of_range("index out of range");
        return data[i];
    }
};

int main() {
    FixedArray arr;
    arr[3] = 42;
    std::cout << arr[3] << "\n";   // 42
}

Call Operator (Functor)

#include <iostream>

class Multiplier {
    int factor;
public:
    explicit Multiplier(int f) : factor(f) {}

    int operator()(int x) const { return x * factor; }
};

int main() {
    Multiplier triple{3};
    std::cout << triple(7)  << "\n";  // 21
    std::cout << triple(10) << "\n";  // 30
}
