Por qué un gestor de referencias

A mano: autores mal escritos, años equivocados, citas que no están en la lista y rehacer todo cuando la revista pide otro estilo. Un gestor guarda tus fuentes y sus PDF en una base de datos y genera citas y bibliografía automáticamente. Pero copia los datos que le das: si un campo está mal, la cita sale mal.

Las herramientas de Mendeley

  • Mendeley Reference Manager (escritorio y web, sincroniza) — Mendeley Desktop ya no se puede descargar (desde el 1 de septiembre de 2022).
  • Mendeley Web Importer — extensión para Chrome, Edge y Firefox.
  • Mendeley Cite — complemento de Word (Word 2016 o posterior, Word en línea).
  • Exportar a BibTeX (.bib) para LaTeX. Alternativa libre y de código abierto: Zotero.

Agregar y revisar referencias

Cuatro caminos: Web Importer en la página del artículo, arrastrar el PDF, importar un .bib/.ris de Scopus o Google Scholar, o capturarla a mano. Después revisa cada campo: autores completos, título exacto, revista o congreso, volumen, páginas, año, un DOI que abre y el tipo correcto.

Citar en Word con Mendeley Cite

Insertar cita → insertar bibliografía → cambiar estilo (APA 7 o IEEE) y todo se actualiza. No edites la bibliografía a mano, usa un solo gestor por documento y actualiza las citas después de corregir un campo en Mendeley.

LaTeX y BibTeX en 20 minutos

LaTeX es el estándar en ingeniería; IEEE, Springer y Elsevier dan plantillas. Overleaf lo corre en el navegador. Flujo: Mendeley → Archivo → Exportar → BibTeX → sube refs.bib a Overleaf → \cite{clave} → compilar. Descarga la plantilla del curso (arriba): Overleaf → Nuevo proyecto → Subir proyecto → el ZIP. Entregar en LaTeX es opcional esta semana.
