Notes

Design: class diagram

Person  (abstract base)
 ├── Student      — vector of enrolled course codes, GPA
 └── Professor    — specialisation string

Course              — code, title, capacity, enrolled count
                      owns a Gradebook by value (composition — Rule of Zero)
                      holds a raw non-owning Professor* (association)

Gradebook           — owned by Course (composition)
                      std::map<studentId, Grade>

Department          — owns Course objects via unique_ptr  (composition)
                      shares Professor objects via shared_ptr (aggregation)

RegistrationError   ← std::runtime_error
 ├── CourseFullError
 └── AlreadyEnrolledError

Ownership summary

Relationship Holder Held Smart pointer / member
Composition Department Course unique_ptr<Course>
Aggregation Department Professor shared_ptr<Professor> (ref-counted, shared with caller)
Association Course Professor raw Professor* (non-owning; professor outlives course)
Composition Course Gradebook by-value member (Rule of Zero)

Why shared_ptr for Professor, unique_ptr for Course?

A Professor may be referenced from outside the department (e.g. a scheduling system, a faculty senate record). shared_ptr expresses "multiple owners, last one cleans up."

A Course is an administrative entity: it belongs to exactly one department and has no meaning outside it. unique_ptr expresses "one owner, deterministic cleanup." If you try to copy the unique_ptr you get a compile error — which is the right answer.

Rule of Five / Zero interaction

Course owns a Gradebook (value member) and an unordered_set<string> — all members manage their own lifetime. By the Rule of Zero, Course needs no user-declared destructor, copy constructor, or copy-assignment operator. However, copying a Course would be semantically wrong (two courses with the same code is a bug), so the copy operations are explicitly = delete. Move is = default because the container needs it when vector<unique_ptr<Course>> is resized.

Department follows pure Rule of Zero: all members (string, vector<shared_ptr<...>>, vector<unique_ptr<...>>) already RAII-manage their resources.

Exception hierarchy and RAII safety

RegistrationError   ← std::runtime_error
 ├── CourseFullError        — thrown when enrolled.size() >= capacity
 └── AlreadyEnrolledError   — thrown when student already in enrolled set

Because Course::enroll throws before it mutates any state (the duplicate and capacity checks come first), the system is exception-safe at the basic guarantee level: if it throws, neither the enrolled set nor the student's course list is partially updated.

STL usage map

Container / algorithm Where Why
std::vector<Student> main Contiguous student registry; students have value semantics
std::vector<unique_ptr<Course>> Department Sole ownership, heap lifetime
std::vector<shared_ptr<Professor>> Department Shared ownership
std::map<string, Grade> Gradebook Ordered, keyed by student ID
std::unordered_set<string> Course O(1) duplicate-enrollment check
std::accumulate Grade::average() Sum scores without a raw loop
std::find_if Department::findCourse() Search by predicate over unique_ptr elements
std::sort + lambda main Polymorphic sort by operator< through raw pointers

Exceptions

// ── Exceptions ────────────────────────────────────────────────────────────────
#include <stdexcept>
#include <string>

class RegistrationError : public std::runtime_error {
public:
    explicit RegistrationError(const std::string& msg)
        : std::runtime_error(msg) {}
};

class CourseFullError : public RegistrationError {
    std::string courseCode;
public:
    explicit CourseFullError(const std::string& code)
        : RegistrationError("Course " + code + " is full")
        , courseCode(code) {}
    const std::string& getCourseCode() const { return courseCode; }
};

class AlreadyEnrolledError : public RegistrationError {
public:
    AlreadyEnrolledError(const std::string& sid, const std::string& code)
        : RegistrationError("Student " + sid + " already enrolled in " + code) {}
};

Gradebook

// ── Gradebook ─────────────────────────────────────────────────────────────────
#include <map>
#include <vector>
#include <numeric>    // std::accumulate
#include <iostream>

struct Grade {
    std::vector<double> scores;   // individual assignment scores

    void addScore(double s) { scores.push_back(s); }

    double average() const {
        if (scores.empty()) return 0.0;
        return std::accumulate(scores.begin(), scores.end(), 0.0) / scores.size();
    }
};

class Gradebook {
    std::map<std::string, Grade> records;  // studentId → Grade
public:
    void addScore(const std::string& studentId, double score) {
        records[studentId].addScore(score);
    }

    double getAverage(const std::string& studentId) const {
        auto it = records.find(studentId);
        if (it == records.end()) return 0.0;
        return it->second.average();
    }

    void printReport() const {
        for (const auto& pair : records)
            std::cout << "  " << pair.first
                      << " avg: " << pair.second.average() << "\n";
    }
};

Person, Student, Professor

// ── Person hierarchy ──────────────────────────────────────────────────────────
#include <vector>
#include <string>
#include <iostream>

class Person {
protected:
    std::string id;
    std::string name;
public:
    Person(std::string id, std::string name)
        : id(std::move(id)), name(std::move(name)) {}

    virtual ~Person() = default;

    // Pure virtual — every person introduces themselves differently
    virtual void introduce() const = 0;

    const std::string& getId()   const { return id;   }
    const std::string& getName() const { return name; }

    // Operator overloading (Lecture 04)
    friend std::ostream& operator<<(std::ostream& os, const Person& p) {
        p.introduce();   // virtual dispatch through a reference — polymorphism
        return os;
    }
    bool operator==(const Person& other) const { return id == other.id; }
    bool operator<(const Person& other)  const { return name < other.name; }
};

class Student : public Person {
    std::vector<std::string> enrolledCourses;  // course codes (aggregation)
    double gpa = 0.0;
public:
    Student(std::string id, std::string name)
        : Person(std::move(id), std::move(name)) {}

    void introduce() const override {
        std::cout << "[Student] " << name << " (ID: " << id
                  << ", GPA: " << gpa << ")\n";
    }

    void addCourse(const std::string& code) { enrolledCourses.push_back(code); }
    bool isEnrolled(const std::string& code) const {
        return std::find(enrolledCourses.begin(), enrolledCourses.end(), code)
               != enrolledCourses.end();
    }
    void setGpa(double g) { gpa = g; }
    double getGpa()  const { return gpa; }
};

class Professor : public Person {
    std::string specialisation;
public:
    Professor(std::string id, std::string name, std::string spec)
        : Person(std::move(id), std::move(name))
        , specialisation(std::move(spec)) {}

    void introduce() const override {
        std::cout << "[Professor] Dr. " << name
                  << " — " << specialisation << "\n";
    }
    const std::string& getSpecialisation() const { return specialisation; }
};

Course

// ── Course ────────────────────────────────────────────────────────────────────
#include <unordered_set>

class Course {
    std::string   code;
    std::string   title;
    int           capacity;
    Professor*    instructor;   // non-owning association (Lecture 01)
    Gradebook     gradebook;    // owned by composition, Rule of Zero (Lecture 06)
    std::unordered_set<std::string> enrolled;  // O(1) duplicate check (Lecture 08)
public:
    Course(std::string code, std::string title, int cap, Professor* prof)
        : code(std::move(code)), title(std::move(title))
        , capacity(cap), instructor(prof) {}

    // Copying is semantically wrong — two courses with the same code is a bug.
    // Rule of Five: explicitly delete copy; default move for vector reallocation.
    Course(const Course&)            = delete;
    Course& operator=(const Course&) = delete;
    Course(Course&&)                 = default;
    Course& operator=(Course&&)      = default;

    void enroll(Student& student) {
        // Check first, mutate later — basic exception guarantee.
        // Duplicate check before capacity: already-enrolled beats course-full.
        if (enrolled.count(student.getId()))
            throw AlreadyEnrolledError(student.getId(), code);
        if ((int)enrolled.size() >= capacity)
            throw CourseFullError(code);

        enrolled.insert(student.getId());
        student.addCourse(code);
    }

    void addScore(const std::string& studentId, double score) {
        gradebook.addScore(studentId, score);
    }

    void printRoster() const {
        std::cout << "Course: " << code << " — " << title
                  << " (" << enrolled.size() << "/" << capacity << " enrolled)\n";
        if (instructor)
            std::cout << "  Instructor: Dr. " << instructor->getName() << "\n";
        gradebook.printReport();
    }

    const std::string& getCode()  const { return code;  }
    const std::string& getTitle() const { return title; }
    int  getEnrolledCount()       const { return (int)enrolled.size(); }

    bool operator==(const Course& o) const { return code == o.code; }
    bool operator<(const Course& o)  const { return code < o.code;  }
    friend std::ostream& operator<<(std::ostream& os, const Course& c) {
        return os << c.code << ": " << c.title;
    }
};

Department

// ── Department ────────────────────────────────────────────────────────────────
#include <memory>
#include <algorithm>

class Department {
    std::string name;
    // shared_ptr: professor may be referenced outside the department (Lecture 07)
    std::vector<std::shared_ptr<Professor>> professors;
    // unique_ptr: course lives and dies with the department (Lecture 07)
    std::vector<std::unique_ptr<Course>>    courses;
public:
    explicit Department(std::string name) : name(std::move(name)) {}

    // Rule of Zero — all members handle their own lifetime (Lecture 06)
    ~Department() = default;

    std::shared_ptr<Professor> hireProfessor(
            const std::string& id,
            const std::string& name,
            const std::string& spec) {
        auto prof = std::make_shared<Professor>(id, name, spec);
        professors.push_back(prof);
        return prof;  // caller gets a second shared_ptr — ref-count becomes 2
    }

    Course& addCourse(const std::string& code,
                      const std::string& title,
                      int capacity,
                      const std::shared_ptr<Professor>& prof) {
        courses.push_back(
            std::make_unique<Course>(code, title, capacity, prof.get()));
        return *courses.back();
    }

    Course* findCourse(const std::string& code) {
        auto it = std::find_if(courses.begin(), courses.end(),
            [&code](const std::unique_ptr<Course>& c) {
                return c->getCode() == code;
            });
        return it != courses.end() ? it->get() : nullptr;
    }

    void printSummary() const {
        std::cout << "=== Department: " << name << " ===\n";
        std::cout << "Professors (" << professors.size() << "):\n";
        for (const auto& p : professors) p->introduce();
        std::cout << "Courses (" << courses.size() << "):\n";
        for (const auto& c : courses)   c->printRoster();
    }
};

main — putting it all together

// ── main ──────────────────────────────────────────────────────────────────────
int main() {
    // Build the department
    Department cs("Computer Science");

    auto profA = cs.hireProfessor("P01", "Garcia",   "Object-Oriented Systems");
    auto profB = cs.hireProfessor("P02", "Martinez", "Algorithms & Data Structures");

    Course& oop   = cs.addCourse("CS101", "OOP with C++14", 3, profA);
    Course& algos = cs.addCourse("CS201", "Algorithms",     2, profB);

    // Students live in a flat registry — NOT owned by the department
    std::vector<Student> students = {
        {"S01", "Alice"},
        {"S02", "Bob"},
        {"S03", "Carol"},
        {"S04", "Dave"},
    };

    // Exception-safe enrollment via a local lambda
    auto tryEnroll = [&](Course& course, Student& student) {
        try {
            course.enroll(student);
            std::cout << student.getName() << " enrolled in " << course << "\n";
        }
        catch (const CourseFullError& e) {
            std::cerr << "  [FULL]   " << e.what() << "\n";
        }
        catch (const AlreadyEnrolledError& e) {
            std::cerr << "  [DUP]    " << e.what() << "\n";
        }
    };

    tryEnroll(oop,   students[0]);  // Alice   → OK
    tryEnroll(oop,   students[1]);  // Bob     → OK
    tryEnroll(oop,   students[2]);  // Carol   → OK
    tryEnroll(oop,   students[3]);  // Dave    → CourseFullError  (cap 3)
    tryEnroll(oop,   students[0]);  // Alice   → AlreadyEnrolledError

    tryEnroll(algos, students[0]);  // Alice → OK
    tryEnroll(algos, students[1]);  // Bob   → OK

    // Add grades
    oop.addScore("S01", 92); oop.addScore("S01", 88);
    oop.addScore("S02", 76); oop.addScore("S02", 81);
    oop.addScore("S03", 95); oop.addScore("S03", 97);

    algos.addScore("S01", 85); algos.addScore("S01", 90);
    algos.addScore("S02", 70); algos.addScore("S02", 65);

    std::cout << "\n";
    cs.printSummary();

    // Polymorphic sort (Lectures 03 + 04): virtual dispatch via Person*,
    // sorted by operator< defined on Person.
    std::cout << "\n--- All people ---\n";
    std::vector<Person*> people;
    for (auto& s : students)    people.push_back(&s);
    people.push_back(profA.get());   // raw non-owning ptr from shared_ptr
    people.push_back(profB.get());

    std::sort(people.begin(), people.end(),
        [](const Person* a, const Person* b) { return *a < *b; });

    for (const auto* p : people) p->introduce();
}

Exercises

Capstone Project — University Course Registration System

Build the system described in this lecture from scratch (or extend the provided skeleton examples/capstone.cpp). Your submission must demonstrate every competency below. Read the rubric before writing a single line of code — it tells you exactly what the grader is looking for.

Milestone 1 — Exception hierarchy (Lecture 09)

Implement RegistrationError, CourseFullError, and AlreadyEnrolledError. Write a main() that directly throws and catches each to confirm the hierarchy and what() messages work correctly.

Milestone 2 — Data layer (Lectures 08, 05–06)

Implement Grade, Gradebook, and Course (without enrollment logic yet). Verify that Course is non-copyable and movable. Confirm Gradebook::printReport() produces correct averages using std::accumulate.

Milestone 3 — Person hierarchy (Lectures 02, 03, 04)

Implement Person, Student, and Professor. Confirm that operator<< uses virtual dispatch — calling it on a Person& that refers to a Student should print the student format, not the professor format. Sort a mixed vector<Person*> by operator<.

Milestone 4 — Department and full integration (Lectures 01, 07)

Implement Department with unique_ptr<Course> and shared_ptr<Professor>. Wire up enroll() with exception handling. Reproduce the expected output above exactly.

Milestone 5 — Extensions (choose at least one)

5a — Semester class.

Add a Semester class that owns multiple Department objects via unique_ptr. Expose a method that prints a full academic report (all departments, all courses, grade averages). Use STL algorithms wherever a raw loop would do.

5b — GPA calculation.

After all scores are entered, compute each student's GPA as the average of all their course averages across the system. Expose a query on Department that returns a student's per-course average. Update Student::setGpa() and verify the updated GPA appears in introduce().

5c — Waiting list.

When a course is full, instead of throwing CourseFullError, add the student to a std::queue<Student*> waiting list. Add a Course::drop(Student&) method that removes the student and automatically enrolls the first waiter. Write a test: fill a capacity-2 course, add two students to the waiting list, drop one enrolled student, and verify the first waiter is now enrolled.
