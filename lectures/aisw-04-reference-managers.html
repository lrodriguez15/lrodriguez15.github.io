Why a reference manager

By hand: misspelt authors, wrong years, citations missing from the list, and redoing everything when the journal asks for another style. A manager keeps your sources and PDFs in one database and generates citations and bibliography automatically. But it copies the data you give it — if a field is wrong, the citation is wrong.

The Mendeley toolkit

  • Mendeley Reference Manager (desktop and web, syncs) — Mendeley Desktop can no longer be downloaded (since 1 September 2022).
  • Mendeley Web Importer — browser extension for Chrome, Edge and Firefox.
  • Mendeley Cite — Word add-in (Word 2016+, Word online).
  • Export to BibTeX (.bib) for LaTeX. Free and open-source alternative: Zotero.

Adding and checking references

Four ways: Web Importer on the article page, drag the PDF in, import a .bib/.ris from Scopus or Google Scholar, or type it by hand. Then check every field: full authors, exact title, journal or conference, volume, pages, year, a DOI that opens, and the right type.

Citing in Word with Mendeley Cite

Insert citation → insert bibliography → switch style (APA 7 or IEEE) and everything updates. Don’t edit the bibliography by hand, use one manager per document, and update citations after fixing a field in Mendeley.

LaTeX and BibTeX in 20 minutes

LaTeX is the standard in engineering; IEEE, Springer and Elsevier provide templates. Overleaf runs it in the browser. Flow: Mendeley → File → Export → BibTeX → upload refs.bib to Overleaf → \cite{key} → compile. Download the course template above: Overleaf → New project → Upload project → the ZIP. Submitting in LaTeX is optional this week.
