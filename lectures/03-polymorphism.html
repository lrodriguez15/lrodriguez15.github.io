Polymorphism

virtual override abstract dynamic_cast

Overview

Polymorphism (from Greek: "many forms") allows a single interface to represent different underlying types. In C++, polymorphism comes in two flavours:

  • Compile-time (static) polymorphism — resolved by the compiler: function overloading, operator overloading, templates.
  • Runtime (dynamic) polymorphism — resolved at execution via the virtual function mechanism and a hidden vtable.

Runtime polymorphism is the heart of OOP design: it lets you write code against an abstract interface and swap in different implementations without changing callers.

Notes

Compile-Time Polymorphism

The compiler selects the correct function at compile time based on argument types or template parameters. No runtime overhead. Examples:

  • Function overloading: multiple functions with the same name but different parameter lists
  • Operator overloading: giving custom meaning to operators for user-defined types
  • Templates: generic code parameterised by type (beyond this course's scope for now)

Runtime Polymorphism & virtual

When a base-class function is marked virtual, the compiler creates a vtable (virtual dispatch table) for that class. Each object contains a hidden pointer (vptr) to its class's vtable. A call through a base pointer/reference follows the vptr at runtime to find the correct override.

  • Declare in base class: virtual void draw() const;
  • Override in derived class: void draw() const override;
  • override is a C++11 keyword that asks the compiler to verify the function actually overrides something — use it always
  • final prevents further overriding: void draw() const final;

The vtable in Practice

Each class with at least one virtual function has its own vtable — a static array of function pointers. Every instance holds a pointer to its class's vtable. When you call ptr->draw() through a Shape*, the CPU dereferences the vptr, looks up draw in the table, and jumps to the correct implementation. The cost is one extra indirection per virtual call.

Abstract Classes & Pure Virtual Functions

A pure virtual function (declared with = 0) has no default implementation in the base class. A class with at least one pure virtual function is abstract — it cannot be instantiated directly. Abstract classes serve as interfaces: they define a contract that all concrete subclasses must fulfil.

dynamic_cast

dynamic_cast performs a safe downcast at runtime using RTTI (Run-Time Type Information). It returns nullptr (for pointer casts) or throws std::bad_cast (for reference casts) if the cast is invalid. Use it only when you genuinely need to recover the derived type — frequent use of dynamic_cast often signals a design that should rely more on virtual dispatch.

Code Examples

Compile-Time Polymorphism: Overloading

#include <iostream>

// Same name, different signatures — resolved at compile time
void print(int x)         { std::cout << "int: "    << x   << "\n"; }
void print(double x)      { std::cout << "double: " << x   << "\n"; }
void print(const char* s) { std::cout << "string: " << s   << "\n"; }

int main() {
    print(42);       // calls print(int)
    print(3.14);     // calls print(double)
    print("hello");  // calls print(const char*)
}

Runtime Polymorphism with virtual and override

#include <iostream>
#include <vector>
#include <memory>

class Shape {
public:
    virtual double area() const = 0;       // pure virtual — Shape is abstract
    virtual void   draw() const = 0;
    virtual ~Shape() = default;
};

class Circle : public Shape {
    double r;
public:
    explicit Circle(double r) : r(r) {}
    double area() const override { return 3.14159 * r * r; }
    void   draw() const override { std::cout << "Drawing Circle, area=" << area() << "\n"; }
};

class Rectangle : public Shape {
    double w, h;
public:
    Rectangle(double w, double h) : w(w), h(h) {}
    double area() const override { return w * h; }
    void   draw() const override { std::cout << "Drawing Rectangle, area=" << area() << "\n"; }
};

int main() {
    std::vector<std::unique_ptr<Shape>> shapes;
    shapes.push_back(std::make_unique<Circle>(5.0));
    shapes.push_back(std::make_unique<Rectangle>(4.0, 3.0));
    shapes.push_back(std::make_unique<Circle>(1.5));

    for (const auto& s : shapes)
        s->draw();   // correct override called for each object at runtime
}

Abstract Class as an Interface

#include <iostream>
#include <string>

class Logger {             // pure interface
public:
    virtual void log(const std::string& msg) const = 0;
    virtual ~Logger() = default;
};

class ConsoleLogger : public Logger {
public:
    void log(const std::string& msg) const override {
        std::cout << "[LOG] " << msg << "\n";
    }
};

class FileLogger : public Logger {
    std::string filename;
public:
    explicit FileLogger(const std::string& f) : filename(f) {}
    void log(const std::string& msg) const override {
        // In real code: open file and write. Simplified here:
        std::cout << "[FILE:" << filename << "] " << msg << "\n";
    }
};

void doWork(const Logger& logger) {
    logger.log("Starting work");
    logger.log("Work complete");
}

int main() {
    ConsoleLogger cl;
    FileLogger    fl("app.log");
    doWork(cl);   // runtime dispatch to ConsoleLogger
    doWork(fl);   // runtime dispatch to FileLogger
}

dynamic_cast

#include <iostream>
#include <memory>

class Animal {
public:
    virtual void speak() const = 0;
    virtual ~Animal() = default;
};

class Dog : public Animal {
public:
    void speak()  const override { std::cout << "Woof!\n"; }
    void fetch()  const          { std::cout << "Fetching!\n"; }
};

class Cat : public Animal {
public:
    void speak()  const override { std::cout << "Meow!\n"; }
    void purr()   const          { std::cout << "Purring...\n"; }
};

int main() {
    std::unique_ptr<Animal> a = std::make_unique<Dog>();

    a->speak();   // virtual dispatch — prints "Woof!"

    // Try to treat 'a' as a Dog specifically
    Dog* dog = dynamic_cast<Dog*>(a.get());
    if (dog) {
        dog->fetch();   // safe — we confirmed the runtime type
    }

    // Try an invalid cast
    Cat* cat = dynamic_cast<Cat*>(a.get());
    if (!cat) {
        std::cout << "Not a Cat — cast failed safely\n";
    }
}

Exercises

Exercise 1

Design an abstract base class Instrument with a pure virtual method play(). Derive at least three concrete instruments (e.g., Guitar, Piano, Drums). Store them in a std::vector<std::unique_ptr<Instrument>> and call play() on each element. Verify that the correct overridden method is invoked at runtime.

Exercise 2

Extend the Shape hierarchy from the code examples. Add a Triangle class. Write a free function double totalArea(const std::vector<Shape*>& shapes) that accumulates and returns the sum of all areas using virtual dispatch. Test it with a mixed collection.

Exercise 3

Given the following hierarchy: 

class Employee { public: virtual double salary() const = 0; virtual ~Employee() = default; };
class FullTime  : public Employee { double base; public: FullTime(double b) : base(b) {} double salary() const override { return base; } };
class PartTime  : public Employee { double hourly; int hours; public: PartTime(double h, int hrs) : hourly(h), hours(hrs) {} double salary() const override { return hourly * hours; } };

Write a Payroll class that stores a collection of Employee* pointers, computes total payroll using virtual dispatch, and uses dynamic_cast to count how many employees are PartTime. Print both the total payroll and the part-time headcount.
