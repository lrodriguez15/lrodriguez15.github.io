STL Containers & Algorithms

vector map iterators algorithms

Overview

The Standard Template Library (STL) provides generic, type-safe containers and algorithms that replace manual data structure implementation. Every container manages its own memory, grows dynamically where needed, and exposes a uniform iterator interface that algorithms work against.

This lecture covers the most commonly used containers:

  • std::vector — dynamic array (the default container)
  • std::array — fixed-size stack array with STL interface
  • std::list — doubly-linked list for frequent insertions/removals
  • std::map / std::unordered_map — ordered and hash key-value stores
  • std::set — sorted unique elements

And key algorithms from <algorithm>: sort, find, count_if, for_each, transform.

Notes

std::vector — The Default Container

A contiguous, dynamically resizable array. Elements are stored next to each other in memory — ideal cache behaviour. Random access is O(1); push_back is amortised O(1); insertion in the middle is O(n).

  • push_back(v) / emplace_back(args…) — add to end
  • pop_back() — remove last element
  • size(), empty(), reserve(n) — avoid reallocations
  • operator[] — unchecked access; .at(i) — bounds-checked
  • begin() / end() — iterator range

std::array — Fixed-Size Stack Array

Wraps a C-style array with the full STL interface. Size is a compile-time constant — no heap allocation. Prefer over C arrays when the size is known at compile time.

std::map & std::unordered_map

  • std::map<K,V> — sorted by key (red-black tree); O(log n) lookup/insert.
  • std::unordered_map<K,V> — hash table; O(1) average lookup/insert.
  • Both expose operator[], .at(key), .find(key), .count(key).
  • operator[] on a map inserts a default value if the key is absent — use .at() or .find() to avoid this.

Iterators

An iterator is an object that points into a container, similar to a pointer. All STL containers expose begin() (points to first element) and end() (one-past-last). The range-based for loop desugars to iterator usage.

Common Algorithms (<algorithm>)

  • std::sort(begin, end) — sort in-place
  • std::find(begin, end, val) — returns iterator to first match
  • std::count_if(begin, end, pred) — count elements satisfying a predicate
  • std::for_each(begin, end, fn) — call fn on each element
  • std::transform(in_begin, in_end, out_begin, fn) — map a function over a range
  • std::accumulate(begin, end, init) — fold/reduce (in <numeric>)

Code Examples

std::vector — Core Operations

#include <vector>
#include <iostream>

int main() {
    std::vector<int> nums;
    nums.reserve(5);           // pre-allocate — avoids repeated reallocations

    for (int i = 1; i <= 5; ++i)
        nums.push_back(i * 10);

    // Range-based for
    for (int n : nums)
        std::cout << n << " ";   // 10 20 30 40 50
    std::cout << "\n";

    nums.erase(nums.begin() + 2);  // remove element at index 2 (value 30)

    std::cout << "size: " << nums.size() << "\n";  // 4
    std::cout << "at(1): " << nums.at(1) << "\n";  // 20 (bounds-checked)
}

vector of Polymorphic Objects

#include <vector>
#include <memory>
#include <iostream>

class Shape {
public:
    virtual void draw() const = 0;
    virtual ~Shape() = default;
};
class Circle    : public Shape { public: void draw() const override { std::cout << "Circle\n";    } };
class Rectangle : public Shape { public: void draw() const override { std::cout << "Rectangle\n"; } };
class Triangle  : public Shape { public: void draw() const override { std::cout << "Triangle\n";  } };

int main() {
    std::vector<std::unique_ptr<Shape>> scene;
    scene.push_back(std::make_unique<Circle>());
    scene.push_back(std::make_unique<Rectangle>());
    scene.push_back(std::make_unique<Triangle>());

    for (const auto& s : scene)
        s->draw();   // runtime dispatch per element
}

std::array — Fixed-Size

#include <array>
#include <numeric>   // std::accumulate
#include <iostream>

int main() {
    std::array<double, 4> temps = {36.5, 37.1, 36.8, 38.0};

    double avg = std::accumulate(temps.begin(), temps.end(), 0.0) / temps.size();
    std::cout << "Average temp: " << avg << "\n";

    // Structured bindings (C++17 preview — works in C++14 with indices)
    for (std::size_t i = 0; i < temps.size(); ++i)
        std::cout << "Day " << i+1 << ": " << temps[i] << "\n";
}

std::map — Key-Value Store

#include <map>
#include <string>
#include <iostream>

int main() {
    std::map<std::string, int> grades;
    grades["Alice"] = 95;
    grades["Bob"]   = 82;
    grades["Carol"] = 88;

    // Iterate in alphabetical key order
    for (const auto& pair : grades)
        std::cout << pair.first << ": " << pair.second << "\n";

    // Safe lookup — .find() doesn't insert a default value
    auto it = grades.find("Bob");
    if (it != grades.end())
        std::cout << "Bob's grade: " << it->second << "\n";

    // Check existence
    std::cout << grades.count("Dave") << "\n";  // 0 — not found
}

Algorithms: sort, find_if, count_if, transform

#include <vector>
#include <algorithm>
#include <iostream>
#include <string>

struct Student {
    std::string name;
    int         grade;
};

int main() {
    std::vector<Student> students = {
        {"Alice", 95}, {"Bob", 72}, {"Carol", 88}, {"Dave", 60}, {"Eve", 91}
    };

    // Sort by grade descending
    std::sort(students.begin(), students.end(),
        [](const Student& a, const Student& b) { return a.grade > b.grade; });

    // Count students who passed (grade >= 70)
    int passed = std::count_if(students.begin(), students.end(),
        [](const Student& s) { return s.grade >= 70; });
    std::cout << "Passed: " << passed << "\n";  // 4

    // Find first student with grade < 70
    auto it = std::find_if(students.begin(), students.end(),
        [](const Student& s) { return s.grade < 70; });
    if (it != students.end())
        std::cout << "At risk: " << it->name << "\n";

    // Print sorted ranking
    for (const auto& s : students)
        std::cout << s.name << " - " << s.grade << "\n";
}

Exercises

Exercise 1

Read a sequence of integers from the user until 0 is entered. Store them in a std::vector. Then: (a) print the sorted sequence; (b) print the sum and average using std::accumulate; (c) print only the even numbers using std::copy_if into a second vector; (d) remove all duplicates (hint: sort first, then std::unique + erase).

Exercise 2

Build a simple word-frequency counter using std::unordered_map<std::string, int>. Read words from a hardcoded string (split by spaces). Print the top-5 most frequent words by transferring the map contents into a vector<pair<string,int>> and sorting by frequency.

Exercise 3

Model a student roster using std::map<std::string, std::vector<int>> where the key is the student's name and the value is a list of assignment scores. Write functions to: add a score for a student, compute each student's average, and print the class ranked by average (highest first). Use STL algorithms throughout.
