The four exercises are the four things for is for: read exactly n things, keep the best one, do something for every pair (a loop inside a loop), and draw. None is hard. All four have a boundary — n = 0, n = 1, the first row — and the shell is where you check it.

Opener — Which book do you throw out? (10 min)

Algorithms to Live By, chapter 4, Caching. Your backpack holds four books. You are carrying four, and you need a fifth. One has to go. Which?

Take three answers. “The biggest.” “The one I like least.” “The one I used longest ago.” The third one is the computer’s answer, and it has a name: LRU — Least Recently Used. Every cache in every computer you own — the processor’s, the browser’s, your phone’s — evicts the item that was touched longest ago, because the best predictor of needing something soon is having needed it recently. Belady proved in 1966 that the truly optimal rule needs to know the future; LRU is the best you can do without it. The book’s extension: your desk, your closet, your phone’s home screen — put what you used last on top, and the thing at the bottom is the one to drop.

How do you find the least recently used of four books? You look at each one, remember the oldest so far, and replace it when you see an older one. That is a loop over a known number of things with a best-so-far inside it — today’s exercise 2, with “oldest” instead of “largest”.

Your turn, 3 minutes, on paper: INPUT: four books, each with the date you last opened it. OUTPUT: the one to remove. Numbered steps: the loop, the memory for the oldest so far, the comparison. Underline the line that says how many times the loop runs.

Exercise 1 — average_of(n) (read exactly n things)

Open 01_average_of.py:

def average_of(n):
    total = 0
    for i in range(n):
        prompt = "Number " + str(i + 1) + ": "
        value = float(input(prompt))
        total = total + value
    return total / n

Shell: average_of(3) with 10 20 30 → 20.0. The for counts the inputs; no asked variable, no step line — compare with lecture 5’s positive_sum. The prompt shows i + 1 because range(3) gives 0, 1, 2 and humans count from 1; str(i + 1) turns the number into text so + can join it.

Now the boundary: average_of(0). The loop runs zero times — no error — and then 0 / 0. The margin note from week 1, for the last time: the loop is safe, the line after it is not, so main refuses n <= 0 before calling.

Exercise 2 — max_of(n) (keep the best one)

Open 02_max_of.py:

def max_of(n):
    best = float(input("Number 1: "))
    for i in range(2, n + 1):
        prompt = "Number " + str(i) + ": "
        value = float(input(prompt))
        if value > best:
            best = value
    return best

Shell: max_of(3) with 4 9 2 → 9.0. max_of(1) with 7 → 7.0: the loop runs zero times and the first value is the answer. That is the opener’s LRU loop with > instead of “older than”. Compare with lecture 5’s maximum = None: there we did not know whether any value would come; here n ≥ 1 is promised, so the first read is the start. The start of a best-so-far is the first candidate, not an invented one. (best = 0 would be wrong for -4 -9 -2.)

Exercise 3 — table(n) and all_tables(up_to) (a loop inside a loop)

Open 03_table.py:

def table(n):
    for i in range(1, 11):
        print(n, "x", i, "=", n * i)

def all_tables(up_to):
    for n in range(1, up_to + 1):
        table(n)
        print()

table(7) prints ten lines. all_tables(3) prints the tables of 1, 2 and 3 — thirty lines plus three blank ones. Before running all_tables(12), say how many lines: 12 × 10 = 120. The inner loop runs completely for every single turn of the outer one; turns multiply. When a program is slow, this is where to look first — a loop inside a loop inside a loop is n³, and n = 1000 is a billion.

Notice the shape: the inner loop is a function call. all_tables does not know how table works and does not need to. That is week 2’s lesson applied to loops — and it is how your project’s main() will call grafica1(tablero) without knowing what a plot is.

Exercise 4 — bars(n) and pyramid(n) (draw)

Open 04_bars.py:

def bars(n):
    for i in range(1, n + 1):
        print("*" * i)

def pyramid(n):
    for i in range(1, n + 1):
        print(" " * (n - i) + "*" * (2 * i - 1))

bars(3) → *, **, ***. "*" * i is a string repeated i times — the thing QE1’s A2 warned you about ("5" + "3" is "53"), now useful. pyramid(3) needs n − i spaces then 2i − 1 stars; trace row 1 before running: 2 spaces, 1 star. bars(0) prints nothing and raises nothing — range(1, 1) is empty.

Exercise 5 — spread(trials, repeats) (Monte Carlo’s price)

Open 05_spread.py — Tuesday’s stretch 1, as a program: run estimate_pi(trials) ten times, report largest minus smallest, for 100, 10 000 and 1 000 000 darts. Typical: 0.7, 0.05, 0.005. A hundred times more work buys ten times less spread. The square root. That is why Monte Carlo is a last resort and why, when it is the only resort, it needs a fast computer. Code Examples

01_average_of.py

# 01_average_of.py — read exactly n numbers. A for loop that counts the inputs for you.

def average_of(n):
    """Ask for n numbers and return their average. n must be positive."""
    total = 0
    for i in range(n):
        prompt = "Number " + str(i + 1) + ": "
        value = float(input(prompt))
        total = total + value
    return total / n


def main():
    n = int(input("How many numbers? "))
    if n <= 0:
        print("Need at least one number.")
    else:
        print("Average:", average_of(n))


main()
# average_of(3) with 10, 20, 30 -> 20.0.  Why the check in main? average_of(0) would divide by zero —
# the for loop runs zero times and that is fine; the division after it is not.

02_max_of.py

# 02_max_of.py — the best-so-far pattern: remember the winner, replace it only when beaten.

def max_of(n):
    """Ask for n numbers and return the largest. n must be positive."""
    best = float(input("Number 1: "))         # the first one is the best so far, by definition
    for i in range(2, n + 1):
        prompt = "Number " + str(i) + ": "
        value = float(input(prompt))
        if value > best:
            best = value
    return best


def main():
    n = int(input("How many numbers? "))
    if n <= 0:
        print("Need at least one number.")
    else:
        print("Largest:", max_of(n))


main()
# max_of(3) with 4, 9, 2 -> 9.0   max_of(1) with 7 -> 7.0 (the loop runs zero times)
# Compare with lecture 5's maximum = None: here we know there is at least one value, so no None.

03_table.py

# 03_table.py — a loop inside a loop. The inner one runs completely for every turn of the outer one.

def table(n):
    """Print the multiplication table of n, from 1 to 10."""
    for i in range(1, 11):
        print(n, "x", i, "=", n * i)


def all_tables(up_to):
    """Every table from 1 to up_to — the inner loop runs 10 times per outer turn."""
    for n in range(1, up_to + 1):
        table(n)
        print()                       # a blank line between tables


def main():
    n = int(input("Which table? "))
    table(n)


main()
# all_tables(3) prints 30 lines. How many lines does all_tables(12) print? Say it before running.

04_bars.py

# 04_bars.py — a picture drawn by a loop. "*" * 3 is "***": a string repeated, week 2's trick with a job.

def bars(n):
    """n rows: 1 star, 2 stars, ..., n stars."""
    for i in range(1, n + 1):
        print("*" * i)


def pyramid(n):
    """Centred: spaces first, then stars. Row i has 2i - 1 stars."""
    for i in range(1, n + 1):
        print(" " * (n - i) + "*" * (2 * i - 1))


def main():
    n = int(input("Rows: "))
    bars(n)
    pyramid(n)


main()
# bars(3) -> *, **, ***.   pyramid(3) -> "  *", " ***", "*****".  bars(0) prints nothing, no error.

05_spread.py

# 05_spread.py — how many darts? Tuesday's stretch 1, measured: a loop around estimate_pi.
import random


def estimate_pi(trials):
    inside = 0
    for i in range(trials):
        x = random.random()
        y = random.random()
        if x * x + y * y <= 1:
            inside = inside + 1
    return 4 * inside / trials


def spread(trials, repeats):
    """Run estimate_pi(trials) `repeats` times; return largest - smallest."""
    smallest = estimate_pi(trials)
    largest = smallest
    for i in range(repeats - 1):
        value = estimate_pi(trials)
        if value < smallest:
            smallest = value
        if value > largest:
            largest = value
    return largest - smallest


def main():
    for trials in (100, 10000, 1000000):
        print(trials, "darts -> spread over 10 runs:", round(spread(trials, 10), 4))


main()
# 100x more darts -> about 10x less spread. The square root. That is Monte Carlo's price.
